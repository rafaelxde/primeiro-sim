PRIMEIRO SIM - SITE

1. Abra index.html e localize:
   const CHECKOUT_URL = 'COLE_SEU_CHECKOUT_AQUI';
2. Troque pelo link do seu checkout (Kiwify, Hotmart, etc.).
3. Publique a pasta na Vercel.
4. O plano inicial pode usar o endereco *.vercel.app gratuitamente.
5. Dominio proprio pode ser conectado depois.

IMPORTANTE: nao publique o PDF pago dentro da pasta publica do site.
