# PRIMEIRO SIM — Landing Page

Landing page estática pronta para deploy na Vercel.

## Arquivos
- `index.html` — página completa, responsiva e sem dependências externas.
- `vercel.json` — configuração básica de hospedagem.

## Checkout
Antes de vender, altere no final de `index.html`:

```js
const CHECKOUT_URL = 'COLE_SEU_CHECKOUT_AQUI';
```

para o link real do checkout.
